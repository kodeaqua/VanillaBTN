# Third-party dependencies

The Windows/Android game host and optional GPU probes use SDL3; normal data-free
unit builds do not download or link it. No third-party PSX API implementation
has been imported.

| Dependency | Version | License | Source |
| --- | --- | --- | --- |
| SDL3 | 3.4.18 | zlib | https://github.com/libsdl-org/SDL/releases/tag/release-3.4.18 |

The official SDL3-3.4.18.tar.gz asset is pinned to SHA-256
9c75cf16330322c217dedd2e0609f1124f1b54b8633e763467b4684d0f4334a3,
verified against the publisher's GitHub release asset digest. FetchContent keeps
the source and its LICENSE.txt in ignored build output. SDL's own notices remain
intact. The library links statically and uses the system GPU driver. Android
disables optional Vulkan features unused by the compute-only scene renderer so
devices that lack shader clip distance can still create an SDL_GPU device.
The checked-in Android Java glue under
`port/packaging/android/app/src/main/java/org/libsdl/app/` is synchronized to
the same 3.4.18 release so its JNI signatures match the native library.
Packaging must retain applicable SDL/bundled notices.

Windows host tools (downloaded to ignored `build/host-tools/`, not vendored):

| Tool | Version | License | Source |
| --- | --- | --- | --- |
| LLVM-mingw | 20250709, Clang 20.1.8 | LLVM Apache-2.0 with LLVM exceptions; mingw-w64 permissive component notices | https://github.com/mstorsjo/llvm-mingw/releases/tag/20250709 |
| CMake | 3.31.6 | BSD-3-Clause | https://github.com/Kitware/CMake/releases/tag/v3.31.6 |
| Ninja | 1.12.1 | Apache-2.0 | https://github.com/ninja-build/ninja/releases/tag/v1.12.1 |

Archive SHA-256 pins are in `port/packaging/windows/setup-toolchain.ps1`.
CMake was checked against its published SHA-256 manifest. LLVM-mingw and Ninja
pins were computed from the official GitHub release downloads, not independently
signed publisher manifests. Tool packages retain their own third-party notices.
Release test executables import Windows system UCRT/API DLLs. Sanitizer tests
also load the toolchain's ASan runtime DLL from PATH; no tool package or
third-party runtime DLL is redistributed by this change. Distribution notice
review remains required when packaging the actual game.

Matching-only tools remain separate: see `NATIVE_BUILD.md` and
`tools/maspsx/LICENSE`. Proprietary SDK headers/libraries are local build inputs,
never port code or distribution content. No third-party PSX implementation has
been imported or approved.

The SPU Gaussian table records numeric PS1 hardware coefficients published in
the psx-spx hardware specification, not a third-party implementation or SDK
asset. Decoder, envelope and interpolation code are original port code. Public
reference: https://psx-spx.consoledev.net/soundprocessingunitspu/. Analytic pitch
and trigonometric tables are generated by this repository's own scripts; they
do not contain proprietary SDK tables. Hardware/SDK parity still needs testing.

The XA zigzag table likewise records numeric hardware interpolation coefficients
from https://psx-spx.consoledev.net/cdromformat/. The sector decoder, bounded
transport ring and mixing integration are original port code. The public
reference notes interpolation-rounding uncertainty; no SDK or emulator source
was imported. This adds no linked third-party dependency.

## Developer-only shader compiler

DirectXShaderCompiler v1.8.2505.1 (Windows binaries 1.8.2505.32), official release:
https://github.com/microsoft/DirectXShaderCompiler/releases/tag/v1.8.2505.1.
Source components use MIT/NCSA; the downloaded package also retains separate
LICENSE-MS terms for its validation components. The package stays in ignored
build/host-tools and is neither linked nor redistributed with the game.

packaging/windows/build-shaders.ps1 pins official dxc_2025_07_14.zip SHA-256:
9ad895a6b039e3a8f8c22a1009f866800b840a74b50db9218d13319e215ea8a4.
This digest was computed from the official release download, not independently
verified against a signed publisher manifest. Regeneration compiles only our
CC0 HLSL. Normal builds use checked-in SPIR-V/DXIL C arrays and require no DXC
installation/download. No new runtime dependency or compiler DLL is bundled.
